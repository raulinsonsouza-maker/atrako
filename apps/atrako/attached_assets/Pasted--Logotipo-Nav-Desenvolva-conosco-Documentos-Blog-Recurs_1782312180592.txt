Códigos de erro
Updated: 23 de jul de 2024
Este documento descreve as mensagens de erro que podem ser retornadas pela API do Instagram. Este exemplo de resposta traz um exemplo de código 3600 e subcódigo 2207004 com os subsequentes códigos de erros definidos.
Exemplo de resposta
{
  "error":
    {
      "message": "The image size is too large.",
      "type": "OAuthException",
      "code": 36000,
      "error_subcode": 2207004,
      "is_transient": false,
      "error_user_title": "Image size too large",
      "error_user_msg": "The image is too large to download. It should be less than 8 MiB.",
      "fbtrace_id": "A6LJylpZRKw2xKLFsAP-cJh"
   }
 }
