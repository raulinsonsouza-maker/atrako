Colaboradores
Updated: 18 de ago de 2025
Representa a lista de usuários que são adicionados como colaboradores em um objeto de mídia do Instagram.
Disponível para a API do Instagram com Login do Facebook.
Criação
Esta operação não é compatível.
Leitura
Obtenha a lista de usuários colaboradores e o status dos respectivos convites em um objeto de mídia do Instagram.
GET /<IG_MEDIA_ID>
Limitações
É possível adicionar até 5 contas do Instagram como colaboradores.
Somente usuários do Instagram que habilitaram a marcação como colaborador serão retornados na resposta.
A marcação de colaboradores pode ser feita em imagens, reels e carrosséis no Feed. Os Stories não são compatíveis.
Requisitos
Tipo	Descrição
Tokens de acesso
Usuário: o usuário precisa ter criado o objeto de mídia do Instagram
Permissões
instagram_basic
pages_read_engagement
Caso uma função na Página tenha sido concedida ao usuário do app por meio do Gerenciador de Negócios, você também precisará obter uma destas permissões:
ads_management
ads_read
Sintaxe da solicitação
GET https://graph.facebook.com/<API_VERSION>/<IG_MEDIA_ID>/collaborators&<USER_ACCESS_TOKEN>
Exemplo de resposta
{
  "data": [
    {
      "id": "90010775360791",
      "username": "realtest1",
      "invite_status": "Accpeted"
    },
    {
      "id": "17841449208283139",
      "username": "realtest2",
      "invite_status": "Pending"
    }
  ]
}
Parâmetros de caminho
Espaço reservado	Valor
<API_VERSION>
A versão da API.
<IG_MEDIA_ID>
Obrigatório. A identificação referente à mídia do usuário do app no Instagram.
Parâmetros da string de consulta
Chave	Espaço reservado	Valor
access_token
<USER_ACCESS_TOKEN>
Obrigatório. O token de acesso do usuário do app.
Campos de resposta
Nome do campo	Descrição
id
O ID no escopo do app da conta do Instagram do possível colaborador
invite_status
O status do convite enviado ao possível colaborador. Pode ser:
Accepted
Pending
username
O nome de usuário do perfil do Instagram do possível colaborador
