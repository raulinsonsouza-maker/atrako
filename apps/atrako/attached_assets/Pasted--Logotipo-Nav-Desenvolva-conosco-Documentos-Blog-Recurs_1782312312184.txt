Página
Updated: 11 de jul de 2024
Representa uma Página do Facebook.
Este nó permite:
obter o usuário do Instagram conectado a uma Página do Facebook.
Disponível somente via Login do Facebook para Empresas.
Criação
Esta operação não é compatível.
Leitura
Como obter o usuário do Instagram de uma Página
GET /<PAGE_ID>?fields=instagram_business_account
Retorna o usuário do Instagram conectado à Página do Facebook.
Permissões
Um token de acesso de um usuário do Facebook com as seguintes permissões:
instagram_basic
pages_show_list
Se o token for de um usuário cuja função na Página foi concedida por meio do Gerenciador de Negócios, uma das seguintes permissões também será necessária:
ads_management
ads_read
Exemplo de solicitação
GET graph.facebook.com
  /134895793791914?fields=instagram_business_account
Exemplo de resposta
{
  "instagram_business_account": {
    "id": "17841405822304914"
  },
  "id": "134895793791914"
}
