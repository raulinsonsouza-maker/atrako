# Atrako — Inteligência comercial para vender mais

## Nome

O sistema se chama **Atrako**.

## Objetivo

Aumentar o **faturamento** de quem vende conhecimento, serviços e produtos digitais ou físicos:

- infoprodutores
- mentores
- consultores
- e-commerces
- clínicas e consultórios (e operações comerciais similares)

O Atrako é a **central de dados e inteligência comercial** que conecta aquisição, comportamento, operação e receita — para essa galera **vender mais** com clareza de mercado, não com métricas isoladas.

## O que o Atrako é

Não é “mais um dashboard de ads”.

É a infraestrutura que:

1. **Recebe** dados de mídia, site, social, CRM, WhatsApp, agenda, checkout e pagamentos
2. **Relaciona** a jornada completa até a venda
3. **Opera** CRM, automações, LPs, formulários, agenda e social no mesmo ambiente
4. **Responde e age** via agente de IA (primeira tela): analisar, criar, configurar, publicar e acompanhar

## Princípio

**Toda entrada de dados passa pelo Atrako.**

O cliente conversa com o agente; o dashboard clássico fica em `/insights` como visão secundária.

## Para quem

Quem precisa de inteligência absurda de mercado para decidir:

- de onde vêm as vendas
- qual criativo/campanha gera receita de verdade
- onde a jornada abandona
- o que automatizar no WhatsApp/CRM
- o que criar (LP, form, oferta) para converter mais

## Jornadas que o Atrako acompanha

- Anúncio → Landing Page → Formulário → CRM → WhatsApp → Agendamento → Pagamento
- Anúncio → E-commerce → Produto → Carrinho → Checkout → Compra
- Instagram → Comentário → DM → Landing Page → Cadastro → CRM

## Módulos

| Módulo | Função |
|--------|--------|
| Inteligência / Ads | Mídia + analytics + atribuição até receita |
| CRM | Leads, pipeline, histórico |
| WhatsApp | Automações, recuperação, handoff |
| Social | Comment→DM, inbox, fluxos |
| Agenda | Reserva e confirmação |
| LP + Checkout | Páginas, ofertas, Mercado Pago |
| Formulários | Fluxos condicionais |
| Agente | Interface principal: perguntar → agir |

## Promessa

**Mais faturamento** através de uma central única de inteligência comercial — dados + operação + IA — feita para quem vive de vender.
