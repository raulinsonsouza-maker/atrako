# @atrako/forms

Motor de formulários condicionais (estilo Typeform) para o Atrako.

- `createFormFromBrief` — gera rascunho a partir de um brief do agente
- `resolveNextStep` — ramificação por resposta
- `previewForm` — preview antes de publicar
- `publishFormCompletion` — emite `form.completed` para o CRM/jornada
